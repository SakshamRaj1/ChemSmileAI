HOW IT WORKS

Learn about the workflow of functions and features in a few steps

ChemSmileAI combines search features with sophisticated cheminformatics functions into a single, user-friendly platform that is based on minimum clicks and maximum detailed information and results. This makes it an essential resource for researchers, students, and professionals in the chemical sciences, streamlining the management of chemical information, promoting molecular exploration, and facilitating computational chemistry tasks, thus enhancing both usability and research efficiency.

1

Find a compound

3

Computation of Results

Molecule Similarity Search Engine

A search engine that computes similarity of a molecule to result in all molecules that are similar to it with a Similarity score.

1

Find a compound

Search using SMILES or CHEMBL ID using specific Similarity Threshold.

2

Input validated

Checks whether the input SMILES or CHEMBL ID is valid or not using RDKit and dataset. Proceedd to next step, else raises error in case of wromg input.

3

Extracts information and Canonicalize

Extracts the target molecule's positional index as target_int_id and other details. Incase the input the SMILES, CHEMBL ID will be searhced and vice-versa.

4

Determine computational resources

Calculates the number of worker processes/threads using approximately half of the available logical CPU cores

5

FPSim2 similarity search

Searches the indexed molecular fingerprint .h5 database using: popcount, canonical query SMILES, specified Tanimoto threshold, and calculated number of workers.

6

Process the similarity matches

Iterates through each FPSim2 result, extracts the index and round the similarity score to 6 decimal places. Removes Self-Similarity from appearing in the final result.

7

SVG Genaration

Uses each FPSim2 index to retrieve the corresponding CHEMBL ID and Canonical SMILES. Generates an SVG representation of each similar molecule using

8

Final Result

Sorts all matches in descending order of Tanimoto similarity, placing the most structurally similar molecules first. The route renders the Similarity Engine Results in a structured tabular format.

Delete / Replace Fragment

Deleting and Replacing a particular fragment feature to create another structure.

1

Substructure Search

Enter the SMILES in the search bar and provide a SMARTS pattern to search for a substructure.

2

Check SMARTS Pattern

The SMARTS pattern is converted into a mol object. If the mol object is invalid, an error is displayed. Returns the matching substructure SVG with the matched pattern highlighted. The page also displays the original SMILES, SMARTS pattern, match status, substructure count, highlighted atoms, match indices, and highlighted SVG.

3

Delete or Replace

Delete and Replace options are shown only when the substructure match is present.

4

Delete Fragment

Click ‘Delete Fragment’ to remove the matched substructure. By default, the highlighted SMARTS pattern is used. The function uses RDkit.

5

Replace Fragment

Click ‘Replace Fragment’ to replace the matched substructure. The replacement pattern can be SMILES or SMARTS, but SMILES is preferred. Sanitization of new mol is done to fix valence and implicit hydrogens and prevent chemically incorrect molecules.

Molecule Fingerprint

Provides unique 2048 bits Morgan fingerprint for molecular identification.

1

Input and Validation

The SMILES entered in the search bar is checked using RDKit whether it has a valid mol object or not.

2

Fingerprint Calculation

Every mol object has a unique fingerprint (0/1) bits. A Morgan Fingerprint with nBits=2048, radius = 2 checks structural neighborhoods up to two bonds away from each atom. The fingerprint also contains the stereochemical configurations i.e., information about chirality.

3

Onbits and Index

The bits with value = 1 are onbits, its index is provided.

4

Result

2048 bits Fingerprint, number and index of onbits are provided in structured format.

Molecular Descriptors

Calculates 4 types of descriptors for providing a wide range of properties for predicting behavior.

1

Input and Validation

The SMILES entered in the search bar is checked using RDKit whether it has a valid mol object or not.

2

Descriptors Classify

Classifies the descriptors into 0D, 1D, 2D, and 3D, calculates a total of 38 unique descriptors.

3

Result

These descriptors provide several crucial information about a molecule in 2D as well as 3D coordinates.

2D and 3D Structures

Visual representation makes visualisation easy. 2D and 3D visuals provides this feature.

1

Input and Validation

The SMILES entered in the search bar is checked using RDKit whether it has a valid mol object or not.

2

2D SVG

Computing 2D coordinates and then drawing 2D SVG for staying sharp and clear. Extracted the svg from Drawing Text. This is then safely rendered to the frontend.

3

3D Conformer

3D embedding using ETKDGv3. If embedding fails, Random Coords are used. The molecule is then optimized using MMFF , or UFF if MMFF does not have the necessary parameters for all atoms and atom pairs in the molecule. Using the generated 3D coordinates, Ball-and-Stick 3D model is generated

4

Safely Rendered

This is then safely rendered to the frontend.
